# Chapter 1 — Getting Started with Python

**Weeks 1–2 | 6 contact hours**

---

## Overview

This chapter establishes the foundation for the entire course. You will install Python, explore the interactive shell, and become comfortable with the tools used throughout the semester. No prior Python knowledge is assumed.

---

## Learning Objectives

By the end of this chapter you will be able to:

1. Explain what Python is, why it is used in engineering, and the difference between Python 2 and Python 3.
2. Launch and use the Python REPL from the command line.
3. Describe the IEP tool and explain why modern alternatives are preferred.
4. Install Python 3.12 locally with correct PATH configuration.
5. Open IDLE, write a script in the editor, and run it with F5.
6. Navigate the Jupyter Notebook interface and execute code cells.

## Topics Covered

1. What is Python? (history, interpreted vs compiled, Python 2 vs 3)
2. The Python REPL — `>>>` prompt, expressions, `exit()`
3. IEP — historical context, what it was, why it is superseded
4. Installing Python — downloading from python.org, PATH configuration
5. IDLE — launching, shell window vs script editor, F5 to run
